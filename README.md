# Структура будущего сайта ЮМК

Интерактивный прототип структуры каталога ЮМК для согласования.

В проекте доступны три представления:

- полное дерево разделов и страниц;
- демонстрация будущего каталожного меню;
- классическая интерактивная mind-map.

## Актуальная версия

[Открыть структуру и меню](https://a1reklama.github.io/umk-site-structure/#menu)

Структура обновлена 16.09.2026 по вкладке «Замечания — упорядочено» и последним уточнениям заказчика. Все три представления используют одно дерево `tree-data.js`.

- [Сверка всех правок и состав изменений](docs/changes-2026-09-16.md)

В карточках разделов доступны связанные пункты ТЗ с номерами строк. Нефтегазовый вход демонстрирует переход к стальным задвижкам с условиями «Сталь» и «Нефтяная рабочая среда».

Это прототип структуры. Характеристики, верхний выбор и параметры карточек описаны в требованиях; реальная товарная выдача и фильтрация относятся к разработке сайта. У новых разделов будущие URL и SEO-метаданные ещё не назначены. Старые URL сохранившихся разделов сохранены для последующей подготовки карты адресов. Исходное семантическое ядро не редактировалось.

Исходная версия и история: [Imperil03/umk-site-structure](https://github.com/Imperil03/umk-site-structure).

## Запуск и проверка

Для просмотра достаточно открыть `index.html` либо запустить любой статический HTTP-сервер в корне проекта.

Проверки целостности дерева и связей с ТЗ (Node.js):

```sh
node --test tests/catalog.test.cjs
```

Проверки в браузере (установленный Google Chrome):

```sh
pnpm install --frozen-lockfile
pnpm test:browser
```

Для другого Chromium-браузера задайте `BROWSER_CHANNEL`; для проверки опубликованной версии — `TEST_URL`.
