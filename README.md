# Структура будущего сайта ЮМК

Интерактивный прототип структуры каталога ЮМК для согласования.

В проекте доступны три представления:

- полное дерево разделов и страниц;
- демонстрация будущего каталожного меню;
- классическая интерактивная mind-map.

Данные во всех представлениях синхронизированы и собраны из единой структуры v14.
